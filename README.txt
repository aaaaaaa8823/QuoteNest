# QuoteNest

Небольшой fullstack проект, где пользователи могут просматривать, искать, сохранять и добавлять цитаты.


### Backend
- **Java**
- **Spring Boot 3**
- **PostgreSQL**
- **Flyway** (миграции БД)
- **Lombok**, **MapStruct**

### Frontend
- **React** (с Vite)
- **JavaScript**
- **Axios**

### DevOps
- **Docker Compose** (для PostgreSQL)
- **Git**
